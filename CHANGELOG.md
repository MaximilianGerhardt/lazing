### Added

- **Initial public release.** laz.ing is a local-first, self-hosted AI agent
  runtime (Next.js 16 / TypeScript / Drizzle / SQLite) published under
  AGPL-3.0-or-later. It provides multi-agent workstreams with a mid-course
  correction ("sniper") loop, an org/workspace multi-user model, an event-sourced
  audit trail, scheduled routines, optional web push, and a first-run onboarding
  wizard. The `lazyos` code identifier prefix is a legacy schema kept behind the
  laz.ing brand.
